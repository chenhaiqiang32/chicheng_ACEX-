cad-html-plugin · multi ACEX

URL 导入 · 轮询 · 下载 ZIP

按对接文档三步调用： POST /api/models/import → GET …/status → GET …/download?type=zip。 本地 Demo 用 Service Worker 打开 zip，服务端不落盘预览。

1. 按 URL 导入转换

提交可访问的 .dwg / .dxf 在线地址；服务异步下载并转换，前端轮询 status（null 转换中 / ready 成功 / failed 失败）。

2. 前端解压并打开

选择 multi ACEX .zip。在浏览器内解压并通过 Service Worker 打开（不写服务端 published/）。

    说明

    • 转换成功后下载地址为 /api/models/{jobId}/download?type=zip。
    • Zip 只用于分发；查看器 fetch 的是解压后的 viewer.html + drawing.acex.json + chunks/。
    • .gz 块必须以原始字节返回，不要带 Content-Encoding: gzip。
