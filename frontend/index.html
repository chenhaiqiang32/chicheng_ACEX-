cad-html-plugin · multi ACEX

服务端转换 · 前端解压打开

方式二用 @mlightcad/cad-simple-viewer-cli 把 DWG/DXF 转成 multi zip；再由服务端解压托管到 /packages/…，局域网内可直接分享打开链接。

1. 上传图纸转换

需要本机已启动转换服务（npm run server），并已安装 Chromium。

2. 前端解压并打开

选择 multi ACEX .zip。将上传到服务端解压并托管（不依赖 Service Worker，局域网可用）。

    说明

    • Zip 只用于分发；查看器 fetch 的是解压后的 viewer.html + drawing.acex.json + chunks/。
    • .gz 块必须以原始字节返回，不要带 Content-Encoding: gzip。
    • 也可在转换时加 ?publish=1 让服务端解压并托管到 /packages/…。
